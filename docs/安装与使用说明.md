# 清华网络学堂课程 DDL — 0.4.0 标题同行修订

每门课程只显示最近一个**未来、未提交**的截止时间，例如 `10月21日 · 剩6天`。DDL 放在**课程标题同一行的右侧**，不再在状态栏下面另起一行。标签使用 13px 字号、浅色底、细边框和稍加粗的倒计时，与原课程行的密度保持一致。原课程顺序、作业计数及公告 / 课件 / 讨论 / 答疑 / 问卷保持原样。

长课程名或窄窗口下，标题内容可缩略，日期和倒计时优先完整显示；原课程链接和点击事件保留。悬停可查看完整文字，右侧 `⋯` 可查看完整摘要并手动刷新；菜单以浮层展开，不增加课程卡片高度。只有在网站找不到原 `.hdtitle` 标题节点时，才回退到卡片底部显示，避免丢失提醒。

## 安装或替换

1. 解压交付包，打开 `thu-homework-deadlines.user.js`。
2. 在 Tampermonkey 编辑原脚本，全选并替换为文件的全部内容，保存。版本号仍为 **0.4.0**，描述含“标题同行修订”；请关闭重复旧脚本。
3. 保持学堂已登录，刷新 [学生课程首页](https://learn.tsinghua.edu.cn/f/wlxt/index/course/student/)。
4. 需要核对作业名称或提交状态时，点击网站原有“作业”链接。日期标签悬停可查看完整北京时间，`⋯` 中提供完整摘要和刷新按钮，按 Esc 可收起菜单。

未自动安装脚本或扩展。只需安装用户脚本，无需安装测试依赖。

## 显示规则

| 情况 | 显示 |
| --- | --- |
| 未来 24 小时内，含恰好 24 小时 | 浅红底、深红字 |
| 超过 24 小时，72 小时内 | 浅橙底、深橙字 |
| 超过 72 小时，7 天内 | 浅黄底、深黄褐字 |
| 超过 7 天 | 浅蓝灰底、蓝灰字 |
| 最近 72 小时内逾期 | 小字提示 `逾期N项`，不挡住未来 DDL |
| 逾期超过 72 小时 | 隐藏，也不计入逾期提示 |

每个标签同时写出日期和剩余时间，不只依赖颜色。同一最近时刻有多项作业时，附小字 `N项同截止`。窄窗口中的附加说明可能省略显示，悬停摘要或展开 `⋯` 可查看全文。逾期按实际经过的 72 小时计算，恰好 72 小时保留，超过 1 毫秒即排除。恰好到达截止时刻归为逾期。

不到 1 小时显示“不足1小时”，24 小时内显示整小时，其余显示整天，均向下取整；日期固定为北京时间，跨年保留年份。未知日期显示 `N项日期待核对`，不猜测日期。只有旧逾期或原站未交数为 0 时不增加展示空间；不把请求失败当成无作业。

按最新要求，首页只展示未交摘要，已交状态到原作业页查看。读取中、读取失败、未完整读取、队列暂停都有文字提示；失败原因可见或悬停查看。若提示登录失效，只需在正常学堂页面重新登录后刷新；不需要提供任何登录凭据。

## 数据来源与限制

读取路径保持已工作的 0.4.0 实现：从每个原课程“作业”链接获取该课 ID，临时同源隐藏 iframe 打开网站正常 `beforePageList?wlkcid=…` 页面，等待原网站脚本渲染后，读取实际表格和原 DataTables 分页结果。一次只处理一门课程，不调用此前返回 403 的学期接口，不绕过拒绝访问。

客户端已加载行或服务端正常翻页均核对总数。超过 50 页 / 1500 条、筛选影响、网络错误或未确定加载完成时，明确标记未完整读取；已读部分的最近日期未必是全课最近日期。空白初始 HTML 不等于无作业。原站未交数为 0 时跳过默认读取，不声称独立验证过空列表。

没有自动网络轮询；每分钟只更新已读数据的显示，手动刷新至少间隔 60 秒。若观察到 401 / 403、登录跳转或嵌入失败，停止后续队列，等待正常页面处理后刷新。

权限只匹配准确首页 URL，`@grant none`、`@noframes`，无外部服务、遥测或远程依赖。脚本不读取、打印或保存 Cookie、令牌、密码，也不读取请求头 / 请求体中的校验信息。只在页面内存处理数据，使用安全 DOM 文本操作；不会提交或修改作业、改变提交状态或账户设置。

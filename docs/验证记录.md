## 本次改动与证据

用户最新截图显示：DDL 能读取并关联课程，但旧样式放在状态栏下面，增加卡片高度。本次将提醒移至 `.hdtitle` 标题行右侧，使用 13px 字号、24px 高度、浅底细边框标签；日期与剩余时间保持完整。长标题和附加说明允许省略，悬停或打开 `⋯` 可查看完整内容。刷新菜单以浮层显示，不参与卡片行高；支持 Esc、点击外部收起，且同一时间只打开一个菜单。

只在有提醒的标题行应用布局样式。保留原标题子元素和事件，裸文本才包入可缩略的 span；不依赖猜测的课程名、教师、上课信息类名。没有 `.hdtitle` 时回退至原状态栏下方，避免丢失提醒。原课程顺序、作业计数、状态栏列宽与读取路径保持不变。

已有 Elements 截图核实 `#selfcourse > .item`、`.hdtitle`、`ul.state.stu` 和原作业链接，但 `.hdtitle` 内部当时折叠。因此测试中的直接子元素、嵌套浮动和纯文本三种标题结构属于兼容性合成样例，不声称已核实真实站点内部结构。

## 检查命令与结果

```powershell
node --check .\thu-homework-deadlines.user.js
node .\tests\run-tests.cjs
node .\tests\layout-browser.cjs
```

语法检查通过。30 个 Node 回归在 UTC、Asia/Shanghai、America/New_York 各通过一次，共 90 次，0 失败。完整输出见[历史测试结果](validation/2026-10-15/test-results.txt)。覆盖日期、紧急度、72 小时逾期边界、同截止计数、时区、已交过滤、课程链接关联、正常页面读取、DataTables 分页、读取失败与访问拒绝等原有行为。

浏览器使用本机 Chrome headless、独立测试配置目录和 localhost 合成数据，不使用用户日常浏览器配置或真实课程数据。脚本仅在测试内存中将固定源替换为 localhost；交付版本仍使用正式 HTTPS 源。

- 八门合成课程的关联、原课程顺序和计数；四种紧急度；同截止计数、近期逾期、未知日期、跨年长日期与旧逾期隐藏。
- DDL 与课程标题同行，完整标签在卡片内，不覆盖原状态栏；标准标题结构不增加卡片或标题高度。
- 原状态栏距离卡片顶部、六列相对宽度和行高不变；原标题链接节点、父节点、目标和点击事件保留。
- 原标题直接子元素不垂直溢出，包含嵌套浮动结构及长课程名；零作业和只有旧逾期的卡片不增加展示空间。

- 缺少标题节点时的底部回退及菜单定位；每场景七次正常作业页读取完成，临时 iframe 全部清理。

已查看宽屏与窄屏合成截图。检查中修复了嵌套浮动标题在窄屏下溢出，以及备用布局中菜单可能向左越界的问题。历史截图仅保留在开发机器的 `private-diagnostics/browser-fixture/title-inline-*.png`；新测试截图写入 `artifacts/browser-fixture/`。
